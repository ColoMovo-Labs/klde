# Expressive reference study

The owner supplied a colorful UKUI-style screenshot on 2026-10-17. It is a visual
reference, not a KLDE runtime capture. Its wallpaper and upstream application
marks are not vendored or relicensed here. KLDE retains its original snow-mountain
composition and geometric assets.

The actionable difference from the first preview is stronger hierarchy: saturated
blue/violet primary actions, generous 52-pixel filled sliders with narrow handles,
48-pixel circular tile icons, primary scene cards, smaller secondary chips and
visible state-driven corner changes. Original icons and wallpaper move toward a
cool blue/lilac palette. A green tint and uniform rounded rectangles alone did
not meet the intended Expressive direction.

All interaction transitions remain finite and follow reduced motion. Dark mode
uses a separately readable primary/text pairing. Opaque fallback and disabled
states stay legible. Cloud screenshots, not a build alone, determine whether the
result is coherent. These initial metrics still require 200%/assistive-technology
and hardware review; the source screenshot does not prove KLDE behavior.
