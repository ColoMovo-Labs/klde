# KLDE visual freeze candidate 0.1

This document freezes the mock-first visual language before broad backend work.
It records the current direction; it does not claim that security, compositor
integration or assistive technology are complete.

## Frozen direction

- central-axis composition with a modular top ribbon and a landscape Temporal Capsule;
- soft information-dense surfaces, 48 px ribbon optical band, 4 px base spacing and shared radii;
- clean heavy clock typography without strokes, black veils or decorative halos;
- day/night mountain, sky, sun and moon language across desktop, lock screen and welcome;
- light and dark themes, reduced motion, keyboard focus and graceful offline states;
- System Island as a finite, priority-driven extension of the Temporal Capsule;
- lock screen as a wallpaper-first visual layer with a separate future session-lock backend;
- Welcome/OOBE as a ceremonial, offline-capable flow separate from installation;
- language bootstrap before the branded Welcome page, with interface language
  independent from region, timezone and keyboard/input choices;
- reusable KLDE blue/violet handwritten wordmark with a finite reveal and a
  replaceable upper-body guide asset;
- original KLDE assets and replaceable character artwork with explicit provenance.

## Visual review gates

Every freeze candidate is reviewed at 1366×768 and 1920×1080, plus a dark,
reduced-motion and keyboard-focus state. Review the rendered PNG for optical
centering, text baseline, padding, clipping, border weight, contrast and idle
stability. Geometry overlay captures are diagnostic only and are excluded from
normal screenshots.

## Intentionally unfrozen

Real KWin effects and scripts, secure session locking, system-service providers,
distribution update/account providers, final fursona licensing, GPU benchmark
numbers and the exact application icon catalogue remain open for backend work.
