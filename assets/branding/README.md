# owoDE generated logo

`owode-logo.png` replaces the previous outlined fox face in shared Glyphs,
the launcher/Dock, language bootstrap, application icon and installed desktop
entry. Technical `klde` icon references are retained as aliases to the new mark.
The wallpapers are unchanged.

Created with the built-in image generation tool on 2026-10-30 at the project
owner's request. The final transparent PNG is stored unchanged; the discarded
glowing draft is not used by the application. See `logo-prompt.md` for the brief
and targeted revision. Project asset metadata specifies CC BY-SA 4.0; generated
provenance is stated explicitly rather than attributed to a human illustrator.
No external character or brand assets were supplied to generation. This is
not a trademark clearance or a claim of legal exclusivity.
