# Original assets

The four wallpapers and all icons are original geometric artwork authored for KLDE.
Regenerate them with `python3 tools/generate-assets.py`. No external character,
wallpaper or icon set was copied. The separately licensed font binaries are
documented in [fonts/README.md](fonts/README.md). The small fin/ear silhouette in the launcher
mark is an abstract project symbol, not a franchise character. Files ending in
`-light.svg` use light ink for dark surfaces; full-color paper/folder glyphs keep
the internal contrast of the original drawing.

License: CC-BY-SA-4.0, copyright 2026 KLDE contributors. Attribute the project,
asset filename and source revision, and identify modifications. License metadata
is in `REUSE.toml`; full terms are in `LICENSES/CC-BY-SA-4.0.txt`.

Wallpaper studies: First Light (snow geometry), Abstract (flowing layered vector
ribbons), Quiet (low contrast gradients) and Kemono (ear/tail-like negative space).
These are original vector compositions, not traced OS wallpapers. Auto accent
selects a documented sample palette by wallpaper ID; it is not image extraction.
