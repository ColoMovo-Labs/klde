# Original assets

`first-light.svg` and all icons are original geometric artwork authored for KLDE.
Regenerate them with `python3 tools/generate-assets.py`. No external character,
wallpaper, icon set or font was copied. The small fin/ear silhouette in the launcher
mark is an abstract project symbol, not a franchise character.
