# Wêlai Glow Sans selection

Unmodified SC Normal Regular and Medium from upstream v0.93, source commit
`715f35148a9e023568839b9740908fe1feccbd19`. Copyright 2020 Celestial Phineas; developer Celestial Phineas.
Fonts are OFL-1.1; the font-building code is separately MIT and is not vendored.
Full original font notice and terms: [OFL.txt](glow-sans/OFL.txt).

[Official release](https://github.com/welai/glow-sans/releases/tag/v0.93).
Archive SHA-256: `aa2e1fdb20337113a1d2670b695bfee83910eefa2e48f51c704e5f4a9f8ec9f1`.
Only two unmodified weights are selected; the full family is not bundled. Qt
FontLoader registers them for this application. No system font is installed.
Noto Sans CJK SC and system sans remain fallbacks. No MiSans is included.
